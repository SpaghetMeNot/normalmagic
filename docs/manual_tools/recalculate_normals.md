# Recalculate Normals

![recalculate_weighted](../assets/icons/recalculate_normals.png){width=128}

Found in the **Mesh/Normals** ++"alt"++ + ++"N"++ menu in "Edit Mode".

Calculates weighted normals and mark sharp for selected geometry. This is a tool version of the [Face Weighted Normals](../normal_tools/face_weighted_normals.md) and [Mark Sharp](../other_tools/mark_sharp.md) modifiers.

Normals are stored as "Tangent" custom normals by default, so they follow later edits and deformation. See [Lock Normals](../normal_tools/lock_normals.md) for the difference between "Free" and "Tangent" normals.
