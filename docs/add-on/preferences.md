# Preferences

These options show up under ***Edit/Preferences/Add-ons/normalMagic***

## UI Preferences

- **Show Sidebar Panel.** Enable/disable the add-on's sidebar panel. Expand to specify it's category (default is "Normal Magic")
- **Show Modifier Header.** Enable/disable the [modifier header](../add-on/modifier_header.md). Expand to choose which modifiers show in the quick bar.

## Preferred Smooth Modifier
Choose which smooth modifier gets added with Boolean Pro's cutter "Auto-Smooth" option.

## Asset Library
Checks if asset library exists and lists the path.

- **Automatic Install:** When no asset library is detected, install the asset library from the add-on (recommended).
- **Refresh Asset Library Location:** When manually moving the asset library, detect the new path for the add-on to use.
- **Enable Asset Library:** When a normalMagic asset library exists but is disabled, you can enable from here.
